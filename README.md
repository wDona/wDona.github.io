# wdona.dev

Web personal desarrollada y mantenida por **wDona**.  
Proyecto de código abierto alojado en GitHub Pages, usando un proxy de Cloudflare y sus dominios. 

## 🌐 Descripción

Este repositorio contiene el código fuente de mi página web personal.  
La web funciona como:

- Portfolio de proyectos
- Espacio de experimentación
- Presentación profesional

Está construida con un enfoque minimalista, priorizando rendimiento, claridad y estructura limpia.

---

## 🛠️ Tecnologías utilizadas

- **HTML5**
- **CSS3**
- **Astro** (para generación estática)
- JavaScript básico cuando es necesario
- GitHub Pages para despliegue
- Clouflare DNS para redirecciones de dominio

---

## 🚀 Desarrollo local

### Clonar el repositorio:

```bash
git clone https://github.com/wDona/wdona.github.io.git
cd wdona.github.io
```

### Instalar dependencias

```bash
npm -i
```

### Ejecutar versión local de desarrollo

```bash
npm run dev
```
