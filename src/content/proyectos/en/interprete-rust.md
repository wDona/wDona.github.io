Interpreter for a custom programming language (`.wdona` files), written from scratch in Rust.

It reads the code line by line, analyzes it with a custom parser and runs the instructions: arithmetic, logical and comparison operations, variables, control flow and functions. A work-in-progress project to learn how languages work under the hood.
